Project Name :
বাজার দর (BazarDor)


Short Description :
BazarDor is a responsive web application that helps users explore daily market prices of essential products in Bangladesh. Users can browse products by category, compare current and previous prices, view product details, and manage their accounts.


Technologies Used :
Next.js
React
TypeScript
Tailwind CSS
DaisyUI
Better Auth
MongoDB
React Hot Toast


Five Key Features :
1.Daily Market Prices: View current prices of essential products in Bangladesh.
2.Category-Based Browsing: Explore products across different categories, such as rice, lentils, oil, vegetables, fish, and meat.
3.Product Details & Price Comparison: View product information and compare current prices with previous prices.
4.Sorting & Responsive Design: Sort products by price and use the website on mobile, tablet, and desktop devices.
5.Authentication & Profile Management: Register, sign in, sign out, and update your profile name.
